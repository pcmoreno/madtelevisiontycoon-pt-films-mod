Pacote Português

Eighty Portuguese films, 1981–2005, prepared as ItemTyp 1 entries for EXTERN/DATABASE/MOD/. This page is the handoff: the dataset, the schema contract, what is verified against the game, what remains open, and where the work stands.

Status, 19 October 2026: ready to publish. Titles and names are parodies in the game's own style, every picture is a made-up black-and-white lookalike, and a double-click Windows installer has been tested end to end (uninstall, install, new game). Next up: the mod pages for ModDB and Nexus (§4).

2 · Constraints — verified vs assumed

The first version leaned on the community Mod Creator, a fan tool. Everything below has since been checked against the installed game: its database files (694 vanilla films, 2,773 cast entries) and its packed data, unpacked with repak.

Verified against the game files

  • Blocks for films is 2–4, never 1 (582 films at 2, 107 at 3, 5 at 4). The Mod Creator offers 1–3 and is wrong.
  • Credits holds exactly 4 IDs on all 694 vanilla films: the director, then three actors.
  • Series run 1 block (274 of 277), occasionally 2.
  • AgeRate uses only 0/6/12/16/18.
  • Country has 34 values, 0 USA to 33 Yugoslavia. Portugal is 7. The list was read from the game's film-details code, and every country code used by a vanilla film matches it. The Mod Creator's six-value list was wrong.
  • Film images are 640×480 PNG, named 0001.png upward inside a folder per genre.
  • Mod files replace the game's database. The loader reads DATABASE/MOD/ItemsData.json and only falls back to DATABASE/ItemsData.json when the mod file fails to load. Cast loads the same way. An earlier version of this page said "add"; installing only our 80 films froze a new game. The installer therefore merges the install's current vanilla files with ours.
  • Duplicate IDs are not caught. Check Exist Item ID and Check Exist Cast ID are stubs that always return false. The 9,000,000–9,999,999 range is free in both files.
  • Images: for N = 1…9999 the game tries 000N.png, 00N.png, 0N.png, N.png and stops at the first number with none, so a gap cuts off everything after it. Slot 0 is a test card, so Texture N = file N. Vanilla DRAMA has an unpadded 41.png, which loads fine.
  • The dealer restocks from the database loaded at start-up, so the mod also works with existing save games. Each film rolls against Chance; films owned, for sale or for rent are skipped.
  • With the no modern movies setting on, films from 2000 or later are skipped (37 of ours) and films after 1996 count as premium.
  • Prefixed mod files are not loaded. The community Mod Creator exports MOD/<modname>_items.json and _cast.json and calls that native multi-mod support. Tested on 18 October 2026: none of our films appeared in two new games. The loader (15 October build) has no folder listing at all, only fixed file names; a DATABASE/MODS/ folder exists but only for review texts. So one content mod owns MOD/ItemsData.json at a time.
  • Disabled cast are still credited on films: 277 of the 279 disabled vanilla people (Hitchkock, Kuprick…) appear in film credits. All 194 of ours are disabled.
  • Premium films are sold only at the premium dealer. The 65 vanilla ones are recent releases (2003–2025, median 2023).
  • Cast Rating only matters for the player's own productions (salary, cast review). Licensed films use cast IDs only, for the schedule combination bonus: neighbouring films with the same franchise, genre, lead actor or director.

Unconfirmed

  • Disabled keeps a person out of the film studio's hiring pool. It fits vanilla (dead directors can't be hired) but hasn't been seen in game.
  • Chance works as a weight for how often a film is offered. Ours follow the vanilla rule, so they appear in proportion: about 1 in 15 offers in 1995, 1 in 8 by 2005.
  • The film card shows Potential at about 0.7× the data value (94 → 6.6, 39 → 2.7, 7 → 0.5). Probably an age or time factor the game applies to every film.

How the two scored fields were derived

Potential — log fit across observed admissions, from O Bobo (678 tickets) to O Crime do Padre Amaro (380,671): 3 + 92 × (log10(adm) − log10(678)) ÷ (log10(380671) − log10(678)). Log rather than linear because television flattens the distribution. The 45 without a figure were rescaled onto the same axis by regression on the anchors — those add no information beyond their relative order.

Rating — 60 + 0.5 × (tier of highest award) + 0.15 × (total award points). Base 60 so awards lift rather than define. Read it as award pedigree, not quality: Vale Abraão computes to 69 on two modest festival prizes and is widely held to be among the finest Portuguese films ever made. No award formula can see that.

5 · Build and install

Built and tested in game; last full test 19 October 2026. Everything lives in the project folder; README.md there has the commands. Film data changes go in data/data_overrides.json, because tools/apply_genres.py regenerates films.json.

  1. Cast. tools/build_cast.py → build/CastData.json: 194 entries for 190 people (four both direct and act), IDs 9,000,001–9,000,194, parody names from data/cast_names.csv, all Disabled.
  2. Films. tools/build_items.py → build/ItemsData.json: 80 films, IDs 9,000,001–9,000,080, titles from data/titles.csv, no Premium flags.
  3. Images. tools/convert_stills.py → stills/png/<id>.png: the generated lookalike, greyscale, 640×480 RGBA. _compare.jpg shows each old TMDB still beside its replacement.
  4. Install (development). tools/install_mod.py merges the install's vanilla ItemsData.json and CastData.json with ours into DATABASE/MOD/, numbers our images after the vanilla ones in each genre folder, and writes the real Texture values. It keeps a record of every file it wrote, with fingerprints, in DATABASE/MOD/ and in the project, so --uninstall removes exactly what it added. Re-run after every game update.
  5. Player package. tools/package.py --version 1.0 → build/PacotePortugues-1.0.zip (24 MB): our data and images only, no game data, plus Install.bat/Uninstall.bat and install.ps1 from tools/windows/. install.ps1 runs on Windows PowerShell 5.1 with nothing else installed. 6 · Distribution

Now in the game's own style. Titles and names are parodies, as the game does for its films, and the pictures are made-up lookalikes, not film stills. The synopses are original one-liners. What remains recognisable is what the game itself leaves recognisable: the parodies point at real films and people. On Nexus the pictures need the AI-Generated Content tag; ModDB's rules couldn't be checked. The zip carries no game data. It can't be combined with other content mods that write MOD/ItemsData.json (Real Names, the Polish database), and the mod pages should say so.
